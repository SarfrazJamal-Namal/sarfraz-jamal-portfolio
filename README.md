# Sarfraz Jamal - Portfolio

A modern, responsive portfolio website showcasing my work as a Computer Science graduate specializing in software engineering, web development, and AI/ML integration.

## 🚀 Live Demo

**[View Live Portfolio →](https://sarfraz-jamal-portfolio.vercel.app)**

Visit my portfolio to see my projects, experience, and skills!

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS 4, Framer Motion
- **UI Components**: Radix UI, shadcn/ui
- **Build Tool**: Vite 7
- **Backend**: Node.js, Express.js
- **Package Manager**: pnpm

## 🏃‍♂️ Getting Started

### Prerequisites

- Node.js 18+ 
- pnpm (or npm/yarn)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/sarfraz-jamal-portfolio.git
cd sarfraz-jamal-portfolio
```

2. Install dependencies:
```bash
pnpm install
```

3. Start the development server:
```bash
pnpm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Build for Production

```bash
pnpm run build
pnpm start
```

## 🚀 Deployment

This portfolio can be deployed to:

### Vercel (Recommended)
```bash
vercel
```

### Netlify
```bash
netlify deploy --prod
```

### Manual Deployment
1. Run `pnpm run build`
2. Deploy the `dist/public` folder to your hosting provider

## 📂 Project Structure

```
sarfraz-jamal-portfolio/
├── client/               # Frontend React application
│   ├── public/          # Static assets
│   └── src/
│       ├── components/  # Reusable UI components
│       ├── pages/       # Page components
│       ├── contexts/    # React contexts
│       └── hooks/       # Custom hooks
├── server/              # Express.js server
├── dist/                # Build output
└── assets/              # Source images
```

## 🎨 Customization

To customize the portfolio for your use:

1. Update personal information in `client/src/pages/Home.tsx`
2. Replace images in `client/public/`
3. Modify color scheme in `client/src/index.css`
4. Update projects, experience, and education data
